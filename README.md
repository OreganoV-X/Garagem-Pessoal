# Garagem Pessoal

App pessoal de cuidados com a moto: manutenção por km e tempo (a partir do manual), revisões, rotina, documentos, multas, abastecimentos e financiamento.

- **Tela (esta pasta):** publicada pelo GitHub Pages.
- **Servidor e dados:** Google Apps Script (`Code.gs`) + planilha e pasta no Google Drive do dono. O `Code.gs` **não** fica neste repositório.

Nenhum dado pessoal fica aqui. Na primeira vez em cada aparelho, o app pede o endereço do servidor (`.../exec`) e a senha criada pela função `criarSenha` do Apps Script.
